# 🧭 AI Career Compass

### A Skill-Based Career Recommendation Web Application

AI Career Compass is a Python-based web application designed to help students explore suitable career options based on their skills.

🌐 **Live Demo:** https://ai-career-compass-gayathri.streamlit.app/

## ✨ Features

- 👤 Student name input
- 💡 Skill selection
- 🎯 Skill-based career recommendations
- 🖥️ Simple and user-friendly interface
- 🌐 Publicly accessible web application

## 🎯 Objectives

- Help students explore career options based on their skills.
- Provide career recommendations through a simple web interface.
- Demonstrate the practical use of Python in career guidance.
- Make the application accessible online.

## 🛠️ Technologies Used

- **Python** — Application logic
- **Streamlit** — Web application interface
- **GitHub** — Source code management
- **Streamlit Community Cloud** — Application deployment

## ⚙️ How It Works

1. Open the AI Career Compass website.
2. Enter your name.
3. Select your skills.
4. Click the career analysis button.
5. View the career recommendation generated by the application.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/gayathrimallavarapu2811-hub/AI-Career-Compass.git
```

### 2. Open the project folder

```bash
cd AI-Career-Compass
```

### 3. Install Streamlit

```bash
pip install streamlit
```

### 4. Run the application

```bash
streamlit run app.py
```
